# 🛰️ 사토시 헌터 (Satoshi Hunter)

옛날 컴퓨터 속에 잠들어 있을지 모르는 **코인 지갑 파일, 메모장에 적어 둔 시드(영단어 12·24개), 개인키**를 내 PC 안에서 찾아보는 도구입니다.

> 찾아 드리는 도구가 아니라 **찾아보는 도구**입니다. 대부분의 컴퓨터에서는 아무것도 나오지 않을 수 있습니다.

---

## 🔒 먼저 읽어 주세요 (보안 안내)

- **찾은 건 내 PC 밖으로 안 나가요.** 찾은 내용을 인터넷으로 보내는 코드가 없습니다. 코드는 누구나 열어 볼 수 있습니다.
- **와이파이를 끄고 돌려도 됩니다.** 검사는 인터넷 없이 됩니다. (인터넷에 닿는 건 화면 글꼴과, 내가 직접 [잔액 조회]를 누를 때 여는 공개 블록 탐색기뿐이고, 이때도 *공개 주소*만 전달됩니다.)
- **찾은 영단어 12·24개와 개인키는 어디에도 붙여 넣거나 보내지 마세요.** 웹사이트, 메신저, 이메일, AI 채팅창 모두 마찬가지입니다. 그 글자를 아는 사람이 곧 지갑 주인이 됩니다.
- **"복구해 드려요", "찾아 드려요" 연락은 의심부터 하세요.** 지갑을 찾았다는 사실을 알리는 것만으로도 표적이 될 수 있습니다.
- 검사가 끝나면 결과 리포트(`satoshi_hunter/satoshi_hunter_report.html`)에 찾은 원문이 들어 있습니다. **확인이 끝나면 이 파일을 지우세요.**

---

## 🚀 설치와 실행 (윈도우)

1. **파이썬 설치** — [python.org/downloads](https://www.python.org/downloads/) 에서 받아 설치합니다.
   설치 첫 화면 아래의 **"Add python.exe to PATH"** 칸을 꼭 체크하세요. (이미 파이썬이 있으면 건너뜁니다)
2. **압축 풀기** — 받은 zip 파일을 오른쪽 클릭 → **압축 풀기**.
3. **더블클릭** — 풀린 폴더에서 **`run_hunter.bat`** 을 더블클릭합니다.
   - 처음이면 **[3] 자가 테스트**를 먼저 눌러 보세요. 시험용 가짜 데이터로 탐지기가 잘 도는지 확인합니다.
   - **[1] 빠른 탐색**: 바탕화면·다운로드·문서·지갑 프로그램 폴더(AppData)
   - **[2] 직접 지정**: 옛 드라이브나 외장하드 전체(예: `D:\`, `E:\`)
4. 끝나면 브라우저에 **결과 리포트**가 열립니다.

> 윈도우가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르면 됩니다. 실행 전에 `.bat` 파일을 메모장으로 열어 무엇을 하는지 직접 볼 수 있습니다.

`run_visual_miner.bat` 은 광부 로봇 화면을 먼저 띄우고 검사를 시작합니다. **광부 화면은 연출(데모)** 이고, 실제 검사는 검은 창에서 합니다.

### 맥·리눅스
압축을 푼 폴더에서 `python3 -m satoshi_hunter.hunter` 를 실행하세요. 빠른 탐색은 윈도우 폴더 기준이라, 맥·리눅스에서는 **[2] 직접 지정**으로 홈 폴더를 넣어 주세요. (맥·리눅스는 충분히 시험하지 못했습니다)

## 🔍 무엇을 찾나요

**지갑 파일**
- Bitcoin Core·Litecoin·Dogecoin Core의 `wallet.dat` (이름이 바뀐 파일도 파일 안쪽 표시로 확인)
- Electrum·Sparrow, Exodus·Atomic·Coinomi, Monero, Ethereum 키스토어(`UTC--…`)
- 브라우저 지갑 확장(메타마스크·팬텀 등)의 로컬 보관함, Ledger Live·Trezor Suite 계정 파일

**글자 속 비밀값** (txt·csv·json·md·log 등 글 파일과, 이름에 wallet·seed·지갑 등이 들어간 파일)
- **시드 구문(BIP-39)** — 연달아 적힌 영단어가 공식 단어 2,048개 사전에 다 들어 있는지 맞춰 봄 (12·15·18·21·24단어). 마지막 확인값(체크섬)까지는 보지 않으니, 우연히 걸린 단어 묶음일 수도 있습니다.
- **개인키(WIF)** — 체크섬 계산으로 진짜 형식인지 확인
- **코인 주소** — 비트코인(1·3·bc1), 이더리움, 도지·라이트코인, 트론 등

화면과 리포트에서 시드·개인키는 기본으로 `***` 가려서 보여 줍니다. [👁️ 보기]를 눌러야 보입니다.

## ✋ 찾았을 때 지킬 것

1. **아무에게도 알리지 마세요.** 캡처해서 올리지도 마세요.
2. 시드·개인키를 **인터넷 창에 붙여 넣지 마세요.** "잔액 확인 사이트"에 시드를 넣으라는 곳은 전부 사기입니다.
3. 잔액은 **주소**로만 확인합니다. 리포트의 [잔액 조회] 버튼은 공개 주소만 블록 탐색기로 엽니다.
4. 옮길 때는 공식 지갑 프로그램(예: 공식 사이트에서 받은 Electrum, Bitcoin Core)으로, 천천히 하세요. 확실하지 않으면 멈추고 기다리는 게 낫습니다.
5. 원본 파일은 지우지 말고 **USB 등에 복사본**을 따로 보관하세요.

## 🧪 test_vault 폴더

`satoshi_hunter/test_vault/` 의 파일은 **자가 테스트용 가짜 데이터**입니다. 실제 지갑이 아니고, 들어 있는 주소는 널리 알려진 예시 주소입니다.

---

## 📁 폴더 구성

```
satoshi-hunter/
├── run_hunter.bat          # 더블클릭으로 검사 시작
├── run_visual_miner.bat    # 광부 화면(데모) + 검사
└── satoshi_hunter/
    ├── hunter.py           # 메뉴·실행
    ├── scanner.py          # 폴더를 돌며 파일 검사
    ├── reporter.py         # 결과 리포트(HTML) 만들기
    ├── visual_miner.html   # 광부 로봇 화면(연출)
    ├── detector/           # 시드·개인키·주소 검증, 지갑 파일 탐지
    └── test_vault/         # 자가 테스트용 가짜 데이터
```

파이썬 기본 기능만 씁니다. 따로 설치할 패키지가 없습니다.
